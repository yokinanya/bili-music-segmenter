# bili-music-segmenter

分析直播录像，定位完整单曲并切出演唱片段。界面是歌切专用剪辑控制台：导入本地录像，用 Gemini 快速找出歌曲与切点，在原视频时间轴上听看、校准、标记，最后主动批量导出。支持 yt-dlp 链接下载，任务由 Python 服务持久执行。

需要 Python 3.12、uv、FFmpeg、Node.js 20+。

## 启动

```bash
cp .env.example .env      # 填写 GEMINI_API_KEY
uv sync
uv run -m segment.webui
```

用控制台打印的带令牌地址打开页面。默认监听 `127.0.0.1:7860`，`--port` 可改端口；令牌每次启动更换，普通 API 需要请求头认证。

配置项：

| 变量 | 说明 |
| --- | --- |
| `GEMINI_API_KEY` | 必填，Google Gemini 官方接口密钥 |
| `GEMINI_PROXY` | 需要代理时填写，必须带协议 |
| `GEMINI_AUDIO_MODEL` | 覆盖音频模型，默认 `gemini-3.8-flash`；旧 `.env` 中的值会覆盖默认值 |
| `GEMINI_BASE_URL` | 自定义接入地址，一般留空 |
| `WEBUI_DATA_DIR` | 任务数据目录，默认 `data/webui` |
| `MUSIC_AGENT_NETEASE_COOKIE` | 网易云 Cookie，与下载 Cookie 独立 |

## 工作流程

1. AI 找歌：Gemini 听整段音频，一次给出每首歌的起止点、分类、歌名线索和主播报幕原话，思考级别固定为 `high`。默认按 1200 秒分块，总长不超过一块时整场单次调用。
2. 识曲：Shazam 与网易云分别识别各片段。

同一片段任一识曲方式匹配成功时，另一方式的请求错误不会使片段失败，错误详情仍保留在识曲证据中；没有任何匹配且存在请求错误时仍报失败。两方匹配冲突仍需人工确认。
3. 人工校对：AI 结果只作为可编辑候选进入时间轴，不自动导出。播放原视频，听看并拖动区间两侧或在属性面板输入秒数校准；不一致的识曲结果列出候选供点选或手填。
4. 批量导出：选中歌曲后主动导出。导出使用点击时的草稿快照，后续编辑不会改变进行中的产物；批次 ZIP 用 `001_、002_` 编号前缀避免同名覆盖。

不再有模型二次处理：识曲结果直接决定标题与切分。歌名有疑问时由人工选择，扫描理由和报幕原话保留在 JSON 里供核对。

相邻扫描块的重叠区间在识曲后确认同歌时合并，保留原始区间证据，再延长尾部；仅有相同的模型歌名提示不触发自动合并，不同歌的重叠仍明确报错。人工可用 Ctrl/⌘ 多选后点击“合并（含间隔）”，不要求歌名一致，合并取最早入点与最晚出点，保留首个片段的歌曲信息。

背景录音里的歌不算，只有主播本人清晰持续的演唱才切。切分保留有证据的前奏、尾奏、间奏和换气，跨块去重后结尾延长 2 秒，遇到下一首起点或视频结尾只延长到边界。

## 网易云识曲

同一片段从 6、12、20、30 秒处各识别一次，按归一化歌名多数决；cover、伴奏、纯享版等版本附注算同一票，平票才标记冲突。起点位置会影响结果，不能只取首个命中。

采样串行执行，`--recognizer-timeout` 同时是整体时限：单点超时按剩余时间裁剪（向上取整为整数秒），用尽后跳过剩余采样点并沿用已有结果。单点网络抖动或子进程失败只丢弃该采样点，不会让整首歌无法识别；只有全部采样点都失败时才报错，并带上子进程的真实原因。

指纹工具 `vendor/ncm-afp/audio_match.js` 从 NeteaseCloudMusicApi 4.32.0 提取，Node 直接请求上游，不需要单独启动服务。

## 歌切控制台

导入时素材栏显示当前文件序号、上传 MiB 与百分比；发送完成后明确区分服务端写入校验、媒体信息读取阶段。预览直接读取上传的原录像，显示加载、缓冲或播放失败状态，不再生成预览代理。

FLV 使用 mpegts.js 在浏览器内转封装为分段 MP4，通过 MSE 播放，不重新编码。以点播模式读取关键帧索引，通过 HTTP Range 按需获取原文件，启用精确定位和过期播放缓冲回收；切换素材或卸载播放器时释放连接。媒体 URL 在主线程解析为绝对地址后交给转封装 Worker。其他格式使用浏览器原生播放。FLV 缺少关键帧索引，或浏览器不支持原视频的容器、视频/音频编码时明确报错，不自动转码。播放仍需解码原视频，显卡负载取决于源分辨率、帧率和编码，不能保证解决驱动黑屏问题。

代理转码接口和后台队列已移除，不再要求 AV1 NVENC 预览编码器。旧代理缓存不会自动删除，原录像、波形缓存和最终导出保持原有用途。AI 分析与导出仍为后端任务，关闭页面不影响已提交任务；上传依赖浏览器持续发送文件，断线时需重新上传。

导出弹窗支持本次统一的文件名后缀：例如输入 `-小葵`，`空空.mp4` 导出为 `空空-小葵.mp4`。留空不添加，关闭弹窗后清空；歌曲名及草稿文件名不变。单曲下载与 ZIP 内文件名一致，后缀变化会区分为不同导出快照；非法文件名字符会明确报错。

顶部仅保留项目与主题，左侧细窄工具栏切换歌切、链接下载、用量和设置。主区固定为三栏：素材库（源录像与歌曲区间）、原视频预览、片段属性；底部是全宽时间轴，显示真实音频波形、歌曲区间和播放头。

- `Space` 播放/暂停；`I` / `O` 在播放头设置选中片段入点/出点；`S` 在播放头拆分；`Ctrl/⌘+Z` 撤销，`Shift+Ctrl/⌘+Z` 重做。输入框聚焦时不截获快捷键。
- 鼠标位于时间轴内时，`Ctrl/⌘ + 滚轮` 以鼠标位置为中心缩放时间轴，并拦截浏览器页面缩放；普通滚轮和时间轴外的操作保留浏览器行为。
- 播放栏提供 0–100% 预览音量和静音按钮；取消静音恢复原音量，仅影响试听，不改变源文件或导出音量。
- 选中歌曲区间时，试听播放到该区间出点自动暂停并停在出点；未选中时播放整段录像。选中不会自动开始播放，暂停状态下仍可自由拖动播放位置。
- 切点属性提供开头／结尾微调，默认步长 0.1 秒，可切换 0.01／0.1／1 秒。调整后暂停并定位到新边界，保留片段选择，可撤销；不可越过源视频边界或另一切点。播放栏不再显示 ±5 秒按钮和快捷键说明，原快捷键保持可用。
- 片段选择跟随播放头：重叠时优先保持当前片段，否则选择起点最晚的覆盖片段；主动定位到空隙时清除选择。Ctrl/⌘ 手动多选保持到下一次主动移动播放头，避免干扰合并。到出点自动暂停时保留当前片段，不自动跳到下一首。
- 歌曲列表支持 Shift+单击连续范围选择，以最近手动点击的歌曲为锚点；Ctrl/⌘+单击逐项增减。范围选择不移动播放头，并保留到下一次主动定位。
- 预览进度条和底部时间轴均可按住拖动播放头，松手定位到最终位置；时间轴还支持缩放、横向滚动和拖动区间两侧校准切点。多选后合并会取外包时间范围（包含中间间隔），界面会明确提示。
- 草稿保存到本地 SQLite，刷新后恢复。保存草稿不编码视频；只有导出才生成片段。AI 候选应用为追加，不覆盖手改片段。
- 选中片段后，属性区的“搜索歌曲”打开独立弹窗，查询网易云和 iTunes 元信息并标注来源，不接入 QQ 音乐。歌手仅供搜索参考，不显示最终歌手编辑框。选择歌名后回填并关闭弹窗，同时更新安全的 `.mp4` 导出文件名，文件名也可单独编辑。平台请求失败会明确显示错误。
- 搜索结果的“查看歌词”仅在点击时查询：网易云按歌曲 ID 读取，iTunes 结果按歌名与歌手匹配 LRCLIB 并标明来源。无歌词会明确提示；不会触发音频识别或 AI 分析。
- 顶栏右上角“AI切片”和“导出”分别打开独立弹窗：前者针对当前素材，后者先确认选中歌曲和文件名。关闭弹窗不停止任务。主题仅在顶栏通过无背景图标切换，设置页不重复提供外观开关。
- 通用输入、按钮、开关和滑块复用 Material 组件；波形、播放头、区间拖动保留专用实现。AI切片主按钮在开始/停止间切换，停止处理中禁用；运行时显示当前步骤进度，没有测量总量时使用不定进度动画，支持减少动态效果设置。
- 分析失败时显示素材与步骤的错误；已生成的区间标为部分结果，不代表整个任务成功。“续跑分析”复用成功检查点，即使最初使用了强制重新识别；“重新分析”才按缓存选项开始新任务。
- 扫描分块的 JSON 损坏、时间倒置或越界会带错误说明重新请求一次，不猜测交换时间、不截断越界点位。纠正请求绕过错误响应缓存；成功分块保存独立的校验检查点。仍失败的分块会明确记录错误，其余分块继续识曲并生成可复核的部分结果，任务保持失败状态供续跑；所有分块失败不会显示为“成功但没有歌曲”。该恢复策略固定最多两次请求，可在代码中将 `MAX_SCAN_ATTEMPTS` 设为 `1` 关闭自动纠正。
- 每个扫描请求按实际音频长度生成时间上下限 Schema，置信度限定在 0–1；起止先后关系仍由本地校验。歌名字段只输出作品名，解释集中在 `rationale`。响应诊断记录响应 ID、完成状态、输出字符数及是否有续写令牌，不记录音频或响应正文；无效响应也计入模型用量，避免漏算付费请求。
- 费用统一为 USD，API 使用 `estimated_usd`，页面明确显示 `USD $`；历史任务按原始用量事件重新计算美元估值，不进行汇率换算。费用为内置单价估算，并非供应商账单。
- 模型扫描和识曲结果保存到 SQLite，同一源音频与相同参数可跨分析任务复用；模型扫描还校验实际音频内容、模型、提示词与响应结构。失败请求不缓存，命中缓存不重复累计模型用量。在 AI 抽屉取消勾选“复用识别缓存”可强制重新识别并更新缓存。
- 素材可直接删除：删除源录像及其区间草稿，磁盘上的源文件与已导出视频不受影响；删掉当前打开的素材会自动切到下一个。
- 预览按 Range 流式播放；MKV/FLV/TS 中兼容的 H.264/AAC 流优先无损重封装为 MP4，仅不兼容的视频编码才转为最高 720p H.264。首次准备和缓冲时显示等待状态，同一素材的并发请求共用一次生成，源文件不被修改。

## 链接下载与用量

- 链接页可下载、切片、预览、打包 ZIP；处理队列展示进度、日志与结果。
- 输入录像、任务记录与导出文件都在 `data/webui/`，保留至手动删除。服务重启后未完成任务标记为中断，点击续跑复用成功检查点。
- 历史页面已移除，任务记录可在设置里清除：只删记录，不改动磁盘文件。
- 用量按实际模型请求记账并持久化到 SQLite，跨重启累计；费用按 Gemini 官方价估算，未知价格或缺失 usage 会标记统计不完整。

## 参数

界面只暴露影响结果的选项：最低置信度、最短演唱、最短候选、识曲超时、Shazam 与网易云开关。其余固定在代码中：

任务参数统一在设置页编辑，点击“保存任务参数”后存入 SQLite，跨服务重启保留，并作为所有新 WebUI 任务的默认值；已运行任务及续跑任务保留创建时的参数。AI切片弹窗仅保留临时“复用识别缓存”选项和任务操作。

| 项 | 固定值 |
| --- | --- |
| 扫描块时长 / 上下文 | 1200 秒 / 30 秒 |
| 候选处理并发 | 3 |
| 模型请求并发 | 3 |
| 识曲请求并发 | 2 |
| 网易云识曲并发 | 1 |
| 媒体进程并发 | CPU 数与 2 的较小值 |

## 界面与构建

固定 `@material/web@2.5.0`，蓝紫主题由 `#3f5ad4` 生成，字体与 SVG 图标均本地托管。宽屏为工具栏 + 顶栏 + 素材/播放器/属性三栏 + 全宽时间轴；窗口较窄时三栏纵向堆叠，时间轴保持可操作。

```bash
cd webui
npm ci
npm run release        # 构建并复制到 segment/webui_dist
```

Python 直接托管静态产物，运行时不需 Next.js 服务。改了 `webui/src` 必须重新 `release`，否则界面仍是旧构建。

## 命令行与 Docker

```bash
uv run -m segment.music_agent.cli --media video.mp4 --outdir output
uv run -m segment.music_agent.cli --media video.mp4 --outdir output --analysis-only
docker compose -f compose.api.yaml up --build -d
```

CLI 与 WebUI 共用同一套分析与切片流程；`--analysis-only` 只输出可编辑候选与识曲结果，不编码视频。
